# FaceFree Customer Info Frontend

Customer registration and photo upload interface. Manages face/body photos stored in Google Cloud Storage.

## Part of FaceFree Platform
See the [main README](../../README.md) for full project documentation.

## Tech Stack
- Vanilla JavaScript, HTML, CSS
- No build step required

## Setup
```bash
git clone https://github.com/claud0604/03-06-01-cust-info-front.git
cd 03-06-01-cust-info-front
# Open index.html in browser or use a local server
```

## Deployment
Deployed on Cloudflare Pages. Auto-deploys on push to main.
